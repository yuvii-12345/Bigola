# Bigola

Two universes, one repo:

- **BIGOLA — The Living Cosmos** (`index.html`) — interactive N-body gravity lab, constellation forge, warp drive, ambient sound.
- **BIGOLA: STELLARFALL — Shadow of Gargantua** (`rpg/`) — a cinematic 3D action RPG. Warden Rook holds Kharon-7 beneath a black hole. Built with Three.js (loaded via CDN with fallbacks). No build step — serve the folder and play.

Local play: `python3 -m http.server 8000` → open `/` (cosmos site) or `/rpg/` (RPG).
